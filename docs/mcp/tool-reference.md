# MCP tool reference

Generated from the server source by `scripts/mcp-tool-reference.cjs`. Do not edit by hand;
run `node scripts/mcp-tool-reference.cjs` after adding, renaming, or changing a tool.

The hints column comes from each tool's MCP annotations: `read-only` tools change nothing,
`destructive` tools delete or roll back data, and `external` tools call a system outside SaCMS.

| `get_deployment_source` | read-only, external | Read back the actual files from this workspace's SaCMS Cloud Hosting deployment — call this BEFORE making a targeted revision ("ubah warna header", "kecilkan logo") whenever you don't already have the current source in this conversation, instead of regenerating the whole frontend from scratch or guessing what's there.
