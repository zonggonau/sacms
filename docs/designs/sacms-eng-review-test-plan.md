## Affected Pages & API Routes
- `/api/public/[tenant]/content/[contentType]` — Strapi-compatible REST API (JSONB filtering, search, pagination, Redis cache, rate limiting).
- `/api/public/[tenant]/single/[singleType]` — Single type settings & singleton page content endpoint.
- `/api/public/[tenant]/graphql` — Dynamic GraphQL query engine with auto-generated schema from custom models.
- `/api/mcp/[...transport]` — Model Context Protocol endpoint for remote AI agents (Cursor, Claude Code, Windsurf).
- `/dashboard/[tenant]/content-type-builder` — Schema builder, AI-assisted migration, and visual content model designer.
- `/dashboard/[tenant]/cms/content/[slug]` — Content entry manager, workflow transitions, and auto-slug generation.

## Key Interactions to Verify
- **Multi-Tenant Routing**: Verify cross-tenant data requests are blocked (Tenant A API key cannot read Tenant B content entries).
- **AI Schema Generation**: Test schema planning with diverse business domains (Hotel, E-Commerce, News, Agency Portfolio).
- **Zod 4 Dynamic Validation**: Ensure required, unique, and type constraints validate correctly before storing to DB.
- **Dedicated vs Shared DB Client**: Verify getTenantDb routes dedicated enterprise DB URLs gracefully without crashing.

## Edge Cases
- Invalid API token / expired token returns 401.
- Redis cache invalidation on content publish / unpublish / update.
- Unreachable database connection URL on dedicated enterprise tenant fallback to default safely.

## Critical Paths
1. Tenant creation -> AI schema generation -> REST API consumption via `@sacms/sdk`.
2. Content creation -> Workflow transition (DRAFT -> PUBLISHED) -> Cache invalidation -> Public API HIT.
3. Dedicated DB client pooling and idle connection disconnect (10-minute timeout).
