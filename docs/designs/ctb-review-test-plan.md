## Affected Pages / Routes
1. **Content-Type Builder (`/dashboard/[tenant]/content-type-builder/*`):**
   - Collection Types: `/content-type-builder/content-types` & `/content-type-builder/content-types/edit/[slug]`
   - Single Types: `/content-type-builder/single-types` & `/content-type-builder/single-types/[singleTypeSlug]/edit`
   - Components: `/content-type-builder/components` & `/content-type-builder/components/[componentSlug]/edit`
   - AI Website Builder: `/content-type-builder/aiwebsitebuilder`
2. **Server Actions Cache Purge (`src/actions/*`):**
   - `content-types.ts`, `single-types.ts`, `components.ts`
3. **Legacy Redirection to CMS Studio:**
   - `/content-type-builder/content-types/[slug]` → `/cms/content/[slug]`
   - `/content-type-builder/single-types/[singleTypeSlug]` → `/cms/single-types/[singleTypeSlug]`

---

## Key Interactions to Verify
- **Schema Creation & Update Cache Invalidation:** Creating or updating a schema immediately reflects on the builder list without needing a hard reload.
- **Relational Dependency Guard:** Attempting to delete a ContentType or Component that is currently linked as a relation in another schema returns a clear warning error and halts deletion.
- **Dynamic Field Reordering & Options:** Drag-and-drop field reordering saves field orders correctly to database.

---

## Edge Cases
- **Self-referential Relations:** Content type referencing itself (e.g. parent-child category).
- **Deleted Target in Existing Entries:** Ensuring schema dependency check prevents dangling relations.
